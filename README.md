# 🌌 Yoshino's Cinematic AI & Development Portfolio

Welcome to my personal developer portfolio! This repository contains a modern, highly interactive web experience designed to showcase my journey through Artificial Intelligence, Machine Learning, and Software Development. 

## 🎨 Key Features

- **Cinematic Scroll Animation:** The hero section uses a custom HTML5 Canvas engine to render a smooth, scroll-driven frame-by-frame visual sequence, paired with a dynamic typewriter text effect.
- **Glassmorphism UI:** Built with modern, frosted-glass components, deep blur backdrops, and interactive glowing hover states that feel premium and futuristic.
- **Fully Responsive:** Beautifully optimized layouts for mobile, tablet, and desktop devices without breaking animations.
- **Live Interactive Demos:** Contains live, embedded projects such as a Tic-Tac-Toe game and a multi-language Cookie Tracker right inside the browser.

## 🚀 Featured Projects

The portfolio natively links to and highlights my core projects:
- **Person & Object Detection AI:** Real-time computer vision detection using OpenCV and YOLOv8.
- **Kira AI Assistant:** A personal AI with voice interaction, automation, and memory handling.
- **SmartPath Navigator:** An advanced DSA-based shortest-path routing engine.
- **Kira Stream:** A sleek, cinematic, Netflix-inspired streaming UI.
- **Android Emergency Navigation App:** Smart navigation and emergency calling with real-time location.

## 🛠️ Technology Stack

- **Frontend Core:** Semantic HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Design System:** Custom CSS properties, Glassmorphism, CSS Grid & Flexbox, FontAwesome Icons
- **Animation Engine:** Vanilla JS `requestAnimationFrame`, scroll event listeners, CSS Keyframes
- **Backend Components:** PHP & Java (JSP) for the live Cookie Tracker server examples.

## 📂 Repository Structure

```text
portfolio/
├── assets/                 # Backgrounds, logos, and project cover images
├── Galaxy/                 # Sequential image frames for the cinematic scroll animation
├── js/                     # Modular JavaScript (animations, game logic, cookies, navbar)
├── PHP/ & JSP/             # Server-side scripts for the Cookie Tracker project
├── index.html              # Main single-page application structure
└── style.css               # Core design system and responsive styling
```

## 💻 Local Setup

If you want to run or modify this portfolio locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/yoshinoGrg/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in any modern web browser (or use an extension like VS Code Live Server for the best developer experience).
