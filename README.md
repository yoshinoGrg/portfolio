## 🖥️ Boot Sequence

Every visit starts like a machine waking up:

```text
> Initializing Portfolio...
> Loading AI Core...
> Loading Projects...
> Loading Skills...
> Authentication Success
> Welcome Suraj Gurung
```

Then a small robot takes over: it **dances** while the circuits warm up, then **walks** across the track as the page loads, waves, and lets you in.

> 💡 It plays once per session. Add `?boot=1` to the URL to watch it again.

## ✨ What Makes It Different

| | |
|---|---|
| 🪟 **Liquid Glass** | Frosted nav, cards, and buttons with layered blur, bright specular edges, and soft inner glow. On Chromium browsers an SVG filter adds a subtle lens-like refraction. |
| 🌗 **Light & Dark** | One tap to switch. Your choice is remembered, and it follows your system until you pick one. No flash on load. |
| 🌈 **Aurora Background** | Blue, green, yellow, orange, and white light drifting slowly behind the glass, tuned separately for each theme. |
| 🤖 **Robot Loader** | A tiny character with a dance routine and a walk cycle, drawn in pure SVG and CSS. |
| 🎮 **Playable Demos** | Real code running live in the page: no screenshots, no mock-ups. |
| ♿ **Considerate** | Keyboard-friendly, screen-reader labels, and graceful fallbacks for reduced motion and reduced transparency. |

Plus the small things: a scroll progress bar, a back-to-top button, nav links that light up as you scroll, animated counters and skill bars, and cards that tilt toward your cursor.

## 🧰 Under the Hood

- **No frameworks.** Semantic HTML5, modern CSS, and vanilla JavaScript (ES6+).
- **Theming with CSS variables.** One set of design tokens, two palettes.
- **Glass with `backdrop-filter`** and SVG displacement filters.
- **Motion that stays cheap:** `requestAnimationFrame`, `IntersectionObserver`, and GPU-friendly transforms.
- **Machine learning in the browser** with TensorFlow.js.
- **Backend examples** in PHP and Java (JSP).
